# Projeto CRUD em JavaScript - Agência de Viagens

Projeto desenvolvido em dupla para a disciplina/curso, utilizando JavaScript e Node.js para gerenciar dados via terminal com a biblioteca `@inquirer/prompts`.

-  Pacotes de Viagem

## Como Executar
1. Certifique-se de ter o Node.js instalado.
2. Clone este repositório e abra a pasta do projeto no terminal.
3. Instale as dependências:
   ```bash
   npm install
   ```
4. Execute o programa:
   ```bash
   node crud.js
   ```

## Funcionalidades (CRUD)
- **Cadastrar:** Adiciona um novo pacote com ID gerado automaticamente.
- **Ver todos:** Lista todos os pacotes cadastrados e a quantidade total.
- **Editar:** Atualiza as informações de um pacote existente.
- **Remover:** Exclui um pacote do sistema após confirmação.
